Script reference & examples
{{counter}} — value of first counter layer
{{counter:0000}} — pad to 4 digits
{{counter:Layer name}} — use named counter
{{counter.raw}} — number without prefix/suffix
{{page}}, {{page:000}} — print page
{{date:DDMMYYYY}} — formatted date
{{date+1:YYYYMMDD}} — next day
{{weekday}}, {{weekday:short}} — day name
{{day}}, {{month}}, {{year}}
{{time:HHmm}} — current print time
{{var:route|upper}} — named value, uppercase
{{page|pad:4}} — zero padding
{{var:route|lower}} — lowercase
{{var:route|trim}} — trim spaces
